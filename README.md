# Calculadora de Áreas y Centroides para Ingeniería Civil

## Descripción del proyecto

Este proyecto consiste en el desarrollo de una herramienta computacional capaz de calcular propiedades geométricas básicas de diferentes secciones planas, específicamente el área y las coordenadas del centroide.

El cálculo de centroides es un procedimiento fundamental dentro de la ingeniería civil, debido a su aplicación en el análisis estructural, diseño de elementos de concreto y acero, evaluación de secciones resistentes y determinación de propiedades geométricas necesarias para cálculos posteriores.

El programa permite al usuario ingresar diferentes tipos de geometrías, tales como rectángulos, triángulos, círculos y figuras definidas mediante coordenadas de sus vértices. Posteriormente, realiza el cálculo automático del área, ubicación del centroide y genera una representación gráfica de la sección analizada.


---

# Objetivo

Desarrollar un programa que permita automatizar el cálculo de áreas y centroides de secciones geométricas, reduciendo errores asociados a procedimientos manuales y facilitando la interpretación gráfica de los resultados.


---

# Aplicación en Ingeniería Civil

Las propiedades geométricas de una sección son fundamentales para múltiples aplicaciones dentro de la ingeniería civil, entre ellas:

- Análisis y diseño estructural.
- Determinación del eje centroidal de elementos.
- Cálculo de propiedades mecánicas de secciones.
- Evaluación de elementos sometidos a esfuerzos.
- Modelación de geometrías utilizadas en estructuras de concreto y acero.

El programa desarrollado permite aplicar estos conceptos mediante una herramienta sencilla y reproducible.


---

# Características del programa

El software permite:

- Calcular el área de una sección geométrica.
- Determinar las coordenadas del centroide.
- Representar gráficamente la figura analizada.
- Ubicar visualmente el centroide mediante un punto de referencia.
- Analizar múltiples figuras consecutivas durante una misma ejecución.
